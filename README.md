# Olist E-commerce SQL Analysis

Analysis of ~100k orders from the Brazilian Olist marketplace (2016-2018) using PostgreSQL.

## Tools
PostgreSQL, SQL (joins, CTEs, window functions)

## Structure
- `queries/` — SQL files for each business question
- `insights/` — written findings from each query

## Key findings
- Business processed 99,441 orders generating R$13.2M in revenue
- Top 5 product categories drive 39.7% of revenue
- Credit cards used in 75% of orders
